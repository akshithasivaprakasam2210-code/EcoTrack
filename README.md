# EcoTrack – Campus Sustainability Issue Management System

## Project Overview
EcoTrack is a CRUD-based web application for reporting and managing campus sustainability issues such as electricity problems, water leakage, waste management and other environmental concerns.

## Objectives
- Report campus sustainability issues
- Perform Create, Read, Update and Delete operations
- Search and filter reports
- Validate user input
- Handle API errors and exceptions
- Store data in MySQL
- Provide REST APIs

## Technologies Used
- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- Spring Data JPA / Hibernate
- MySQL
- Postman
- Git & GitHub
- IntelliJ IDEA

## Architecture
User → HTML/CSS/JavaScript → REST API → Spring Boot → JPA/Hibernate → MySQL

## Main Features
- Create sustainability reports
- View all reports
- Update reports
- Delete reports
- Search by location
- Filter by category, status and priority
- Server-side validation
- Exception handling
- Responsive dashboard

## Database
Database: ecotrack_db

Main table: eco_reports

## Setup
1. Create the database:
   CREATE DATABASE ecotrack_db;

2. Set the MySQL password using the DB_PASSWORD environment variable.

3. Open the project in IntelliJ IDEA.

4. Run EcoTrackApplication.

5. Open http://localhost:8080
